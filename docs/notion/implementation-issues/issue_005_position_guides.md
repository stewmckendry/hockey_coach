# Issue #5: Develop Position Guides

## Overview
Create 3 comprehensive position guides for U10 players covering Forward, Defense, and Goalie basics. Each guide will use the iterative workflow and emphasize fundamental responsibilities with 70% visual content.

## Objectives
- Explain each position in kid-friendly terms
- Show positioning with visual diagrams
- Highlight key responsibilities
- Make positions sound fun and important
- Build player confidence in their roles

## Position Guides to Create

### 1. Forward Basics Guide
**Key Topics:**
- What forwards do (score goals, create chances)
- Three forward positions (Center, Left Wing, Right Wing)
- Offensive zone positioning
- Forechecking basics
- Supporting teammates
- When to shoot vs pass

### 2. Defense Basics Guide
**Key Topics:**
- What defenders do (protect the net, start plays)
- Two defense positions (Left Defense, Right Defense)
- Defensive zone positioning
- Gap control basics
- Clearing the puck
- When to join the rush

### 3. Goalie Introduction Guide
**Key Topics:**
- What goalies do (last line of defense, team leader)
- Basic stance and positioning
- Butterfly basics
- Playing the puck
- Communicating with teammates
- Building confidence

## Special Considerations

### Forward Guide
- Emphasize creativity and teamwork
- Show all three forward positions
- Include passing plays, not just goals
- Balance offense with backchecking

### Defense Guide
- Make defense sound exciting (not just "staying back")
- Show how defenders start the offense
- Include joining the rush safely
- Emphasize smart plays over big hits

### Goalie Guide
- Extra focus on building confidence
- Address fear of the puck
- Make it sound fun, not scary
- Include mental preparation tips
