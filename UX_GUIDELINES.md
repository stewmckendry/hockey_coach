# UX Guidelines for Hockey Content Creation

This document provides Claude Code with reference standards for creating age-appropriate, accessible, and effective hockey educational content.

## Quick Reference Age Standards

### U8 (8-9 years) - "Learn Through Play"
- **Visual Ratio**: 80% images/video, 20% text
- **Reading Level**: Grade 2-3 (ages 7-9)
- **Attention Span**: 5-10 minutes maximum
- **Language**: Simple, encouraging, concrete instructions
- **Focus**: Basic motor skills, following directions, having fun
- **Avoid**: Complex diagrams, technical terms without visuals, competitive pressure

### U10 (9-10 years) - "Building Fundamentals"  
- **Visual Ratio**: 70% images/video, 30% text
- **Reading Level**: Grade 3-4 (ages 8-10)
- **Attention Span**: 10-15 minutes
- **Language**: Clear instructions with simple "why" explanations
- **Focus**: Fundamental skills, basic strategy, teamwork
- **Include**: Step-by-step breakdowns, success indicators

### U12 (11-12 years) - "Developing Skills & Strategy"
- **Visual Ratio**: 60% images/video, 40% text
- **Reading Level**: Grade 5-6 (ages 10-12)
- **Attention Span**: 15-20 minutes
- **Language**: Technical terms with clear definitions
- **Focus**: Advanced skills, team systems, game situations
- **Include**: Cause-and-effect explanations, skill progressions

### U14+ (13+ years) - "Advanced Development"
- **Visual Ratio**: 50% images/video, 50% text
- **Reading Level**: Grade 7+
- **Attention Span**: 20-30 minutes
- **Language**: Technical terminology, detailed analysis
- **Focus**: Advanced systems, tactics, mental game, specialization
- **Include**: Strategic thinking, performance analysis

## Hockey Terminology Tiers

### Tier 1 (U8-U10): Basic Terms - Always Define Visually
- Puck, stick, skates, goal, rink, pass, shot, save
- Forward, defense, goalie
- Offside, icing (simple explanation only)

### Tier 2 (U10-U12): Intermediate Terms - Define with Context
- Forechecking, backchecking, breakout
- Power play, penalty kill, faceoff
- Cycle, screen, rebound, one-timer

### Tier 3 (U12+): Advanced Terms - Strategic Context Required
- Neutral zone trap, cycling, odd-man rush
- Weak side, strong side, slot coverage
- Transition game, support angles, board battles

## Content Structure Templates

### Practice Plan Format
```
# Practice Plan - [Focus] ([Age Group])

## Quick Info 📋
- Duration: [X] minutes
- Equipment: [List]
- Focus: [Primary skill]

## Goals 🎯
1. [Specific learning objective]
2. [Skill development goal]
3. [Fun/engagement goal]

## Activities
[Age-appropriate sections with timing]

## Safety Reminders ⚠️
[Key safety points]

## Coaching Notes 👨‍🏫
[Teaching points in expandable section]
```

### Drill Instruction Format
```
# [Drill Name]

## Purpose
**What it teaches**: [Clear objective]
**Best for**: [Age group]
**Time needed**: [Duration]

## Setup 🏗️
[Simple diagram description]
- Equipment: [List]
- Players: [Number needed]

## Steps ▶️
1. [Clear step with visual reference]
2. [Clear step with visual reference]
3. [Clear step with visual reference]

## Key Points 📝
- [Main technique focus]
- [Common mistake to watch]
- [Success indicator]

## Make it Easier/Harder 📈
- Easier: [Beginner modification]
- Harder: [Advanced variation]
```

### Concept Explanation Format
```
# [Concept Name]

## What You'll Learn
[One clear sentence objective]

## Why It Matters
[Simple importance explanation appropriate to age]

## See It in Action
[Description of visual example]

## Break It Down
[Step-by-step explanation with age-appropriate depth]

## Practice It
[How to apply in drills/games]

## Remember This 💡
[Key takeaway appropriate to age group]
```

## Content Quality Self-Evaluation Checklist

### Before Creating Content - Planning Check
- [ ] **Age Group Identified**: Clear target age group (U8/U10/U12/U14+)
- [ ] **Purpose Defined**: Specific learning objective stated
- [ ] **Duration Planned**: Appropriate attention span considered
- [ ] **Equipment Listed**: Required materials identified
- [ ] **Safety Considered**: Potential risks identified

### During Content Creation - Standards Check
- [ ] **Visual Ratio**: Meets age-group requirements (80%/70%/60%/50%)
- [ ] **Language Level**: Appropriate reading level for age group
- [ ] **Terminology**: Uses appropriate tier vocabulary
- [ ] **Structure**: Follows established template format
- [ ] **Instructions**: Clear, step-by-step, actionable
- [ ] **Positive Tone**: Encouraging and supportive language
- [ ] **Hockey Accuracy**: Techniques are correct and safe

### After Content Creation - Quality Check
- [ ] **Completeness**: All required sections included
- [ ] **Clarity**: Instructions are unambiguous
- [ ] **Engagement**: Content maintains interest for target age
- [ ] **Safety**: All safety considerations addressed
- [ ] **Accessibility**: Content works on mobile devices
- [ ] **Consistency**: Formatting and style match guidelines
- [ ] **Value**: Content provides clear learning benefit

## Accessibility Requirements

### Universal Standards
- **Alt Text**: Describe all images and diagrams
- **Clear Headers**: Use consistent H1, H2, H3 structure
- **Mobile-First**: Assume content will be viewed on phones
- **Simple Language**: Prefer active voice and common words
- **Contrast**: Ensure text is readable against backgrounds

### Age-Specific Accessibility
- **U8-U10**: Large text, minimal scrolling, obvious next steps
- **U10-U12**: Scannable sections, clear progress indicators
- **U12+**: Logical information hierarchy, related content links

## Content Creation Best Practices

### Language Guidelines
- **U8**: "Let's try this!" "Great job!" "Watch this!"
- **U10**: "Here's how to..." "This helps you..." "Try this next..."
- **U12**: "The key to this skill..." "When you master this..." "Apply this by..."
- **U14+**: "This technique improves..." "Strategic application..." "Performance indicators..."

### Safety Integration
- Always mention safety first for physical skills
- Include equipment checks for all activities
- Note supervision requirements for younger ages
- Highlight potential risks before activities

### Engagement Techniques by Age
- **U8**: Games, stories, animal movements, color and emojis
- **U10**: Challenges, skill competitions, clear success metrics
- **U12**: Problem-solving, strategy elements, improvement tracking
- **U14+**: Performance analysis, tactical discussions, goal setting

## Common Content Mistakes to Avoid

### Age-Inappropriate Content
- ❌ Technical diagrams for U8 without explanation
- ❌ Complex strategies for U10 without fundamentals
- ❌ Adult coaching language for youth content
- ❌ Competitive pressure language for learning content

### Structure Problems  
- ❌ Too much text without visual breaks
- ❌ Steps that are too complex or numerous
- ❌ Missing safety considerations
- ❌ Unclear learning objectives

### Language Issues
- ❌ Hockey jargon without definitions
- ❌ Passive voice instructions ("The puck should be...")
- ❌ Overly long sentences for younger ages
- ❌ Negative or discouraging language

## Quick Validation Questions

Before publishing any hockey content, ask:

1. **Age Check**: Would a child of this age group understand and engage with this?
2. **Safety Check**: Are all safety considerations clearly addressed?
3. **Clarity Check**: Could a coach with no hockey experience follow these instructions?
4. **Value Check**: Will this content actually help someone improve at hockey?
5. **Fun Check**: Is this content enjoyable and encouraging?
