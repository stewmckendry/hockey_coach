# Hockey Whiteboard Checklist

## Essential Elements for Realistic Hockey Rink Whiteboard

### Rink Dimensions & Shape
- [ ] **Rink Shape**: Rounded corners (not sharp rectangles)
- [ ] **Aspect Ratio**: Approximately 200ft x 85ft (2.35:1 ratio)
- [ ] **Board Frame**: Visible whiteboard frame/border around the rink

### Lines - Color Coding
- [ ] **Red Lines**:
  - [ ] Center red line (divides rink in half)
  - [ ] Two goal lines (near each end)
- [ ] **Blue Lines**:
  - [ ] Two blue lines (divide rink into three zones)
  - [ ] Should be parallel to goal lines
- [ ] **Line Appearance**: Slightly hand-drawn, not perfectly straight

### Face-off Circles & Dots
- [ ] **Center Ice**:
  - [ ] Large circle at center ice
  - [ ] Blue dot in the middle
- [ ] **End Zone Circles** (4 total):
  - [ ] Two circles in each defensive zone
  - [ ] Red face-off dots in center of each
  - [ ] Hash marks around the circles
- [ ] **Neutral Zone Dots** (4 total):
  - [ ] Two dots near each blue line
  - [ ] No circles, just dots

### Goal Areas
- [ ] **Goal Nets**:
  - [ ] Semi-circular or rectangular net shape behind each goal line
  - [ ] Drawn with black/dark marker
- [ ] **Goal Creases**:
  - [ ] Semi-circular blue crease with red outline
  - [ ] In front of each net

### Additional Markings
- [ ] **Referee Crease** (optional):
  - [ ] Small semi-circle at one end (usually bottom)
- [ ] **Bench Areas** (optional):
  - [ ] Indicated along one side

### Whiteboard Aesthetics
- [ ] **Background**: Clean white/off-white surface
- [ ] **Marker Style**: Hand-drawn appearance with slight imperfections
- [ ] **Color Contrast**: Clear distinction between red and blue lines
- [ ] **Overall Cleanliness**: No smudges or excessive marks
- [ ] **Realistic Texture**: Looks like dry-erase marker on whiteboard

### Quality Indicators
- [ ] Lines have consistent thickness
- [ ] Colors are vibrant but realistic (not computer-perfect)
- [ ] Proportions match real hockey rink layout
- [ ] Face-off dots are clearly visible
- [ ] Net areas are properly positioned
