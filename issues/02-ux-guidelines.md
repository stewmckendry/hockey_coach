# Issue 2: UX & Content Guidelines System

## Overview
Create comprehensive UX guidelines and content standards for hockey team educational content. These guidelines will ensure age-appropriate, accessible, and effective content across all team materials while establishing quality checklists for consistent content creation.

## Objectives
- Define age-appropriate content standards for youth hockey (U8-U18)
- Establish visual-to-text ratios optimized for learning
- Create hockey terminology integration guidelines
- Build quality assurance checklists for content validation
- Ensure accessibility compliance across all content formats

## Age-Appropriate Content Guidelines

### U8 (8-9 years) - "Learn Through Play"
**Cognitive Development**: Concrete thinking, short attention spans, learning through repetition and fun

**Content Standards**:
- **Visual Ratio**: 80% images/video, 20% text
- **Text Complexity**: Grade 2-3 reading level (ages 7-9)
- **Attention Span**: 5-10 minute activities maximum
- **Language Style**: Simple, encouraging, concrete instructions
- **Concept Focus**: Basic motor skills, following directions, having fun

**Template Structure**:
```markdown
# [Skill Name] 🏒
**What We're Learning**: [One simple sentence]

## Watch This! 📹
[Large embedded video - 30-60 seconds]

## Let's Try It!
1. [Simple step with emoji] 
2. [Simple step with emoji]
3. [Simple step with emoji]

## Great Job! 🌟
[Positive reinforcement message]

## For Coaches 👨‍🏫
[Coaching points in expandable section]
```

**Prohibited Elements**:
- Complex diagrams with multiple components
- Technical hockey terminology without visual explanation
- Activities longer than 10 minutes
- Competitive comparisons or pressure language

### U10 (9-10 years) - "Building Fundamentals"
**Cognitive Development**: Beginning logical thinking, can follow multi-step instructions, motivated by skill mastery

**Content Standards**:
- **Visual Ratio**: 70% images/video, 30% text
- **Text Complexity**: Grade 3-4 reading level (ages 8-10)
- **Attention Span**: 10-15 minute activities
- **Language Style**: Clear instructions with simple "why" explanations
- **Concept Focus**: Fundamental skills, basic strategy concepts, teamwork

**Template Structure**:

### U14+ (13+ years) - "Advanced Development"
**Cognitive Development**: Formal operational thinking, can handle complex concepts, motivated by competition and improvement

**Content Standards**:
- **Visual Ratio**: 50% images/video, 50% text
- **Text Complexity**: Grade 7+ reading level
- **Attention Span**: 20-30 minute activities
- **Language Style**: Technical terminology, detailed analysis, strategic thinking
- **Concept Focus**: Advanced systems, tactics, mental game, specialization

## Hockey Terminology Integration Guidelines

### Progressive Vocabulary System

**Tier 1 Terms** (U8-U10): Introduce immediately with visual support
- Puck, stick, skates, goal, rink, pass, shot, save
- Forward, defense, goalie
- Offside, icing (basic explanation)

**Tier 2 Terms** (U10-U12): Introduce with context and definition
- Forechecking, backchecking, breakout
- Power play, penalty kill, faceoff
- Cycle, screen, rebound
- One-timer, wrist shot, slap shot

**Tier 3 Terms** (U12+): Advanced concepts with strategic context
- Neutral zone trap, cycling, odd-man rush
- Weak side, strong side, slot coverage
- Transition game, support angles
- Board battles, net-front presence

### Terminology Integration Pattern
```markdown
**[Term]** ([hover definition]): [Usage in context]

Example:
**Forechecking** (pressuring the other team when they have the puck): 
Our forechecking helps us get the puck back quickly so we can score more goals.
```

## Visual Content Standards

### Image Requirements
- **Resolution**: Minimum 1200px width for primary images
- **Aspect Ratio**: 16:9 for videos, 4:3 for instructional stills
- **File Format**: PNG for diagrams, JPG for photos, WebP for web optimization
- **Alt Text**: Descriptive alternative text for all images
- **Captions**: Clear, concise captions explaining what's shown

### Diagram Standards
- **Color Palette**: 
  - Players: Blue (#1B365D) and Red (#E63946)
  - Ice: Light blue (#E8F4FD)
  - Puck: Black (#000000)
  - Movement: Green arrows (#2A9D8F)
  - Key areas: Orange highlights (#F4A261)
- **Clarity**: Large enough text to read on mobile devices
- **Simplicity**: Maximum 5 elements per diagram
- **Consistency**: Same symbols and colors across all content

### Video Integration Guidelines
- **Duration**: 30-90 seconds for skill demonstrations
- **Quality**: 720p minimum, 1080p preferred
- **Sound**: Background music optional, clear narration required
- **Captions**: Closed captions for all instructional content
- **Thumbnails**: Custom thumbnails showing key moment

## Content Quality Checklists

### Pre-Publishing Checklist
- [ ] **Age Appropriateness**
  - [ ] Language matches target age reading level
  - [ ] Concepts are developmentally appropriate
  - [ ] Visual-to-text ratio meets guidelines
  - [ ] Activity duration within attention span limits

- [ ] **Content Structure**
  - [ ] Clear learning objective stated
  - [ ] Step-by-step instructions provided
  - [ ] Visual examples included
  - [ ] Coaching points highlighted
  - [ ] Safety considerations addressed

- [ ] **Hockey Accuracy**
  - [ ] Techniques are correct and current
  - [ ] Rules interpretation is accurate
  - [ ] Equipment usage is safe and proper
  - [ ] Skill progressions are logical

- [ ] **Accessibility**
  - [ ] Alt text provided for all images
  - [ ] Color contrast meets WCAG standards
  - [ ] Content readable on mobile devices
  - [ ] Video captions available
  - [ ] Text can be enlarged to 200%

- [ ] **Engagement**
  - [ ] Visual content supports learning
  - [ ] Interactive elements included where appropriate
  - [ ] Variety in content presentation
  - [ ] Clear next steps or progressions

### Publishing Standards Checklist
- [ ] **Notion Formatting**
  - [ ] Consistent header structure (H1, H2, H3)
  - [ ] Proper use of callout blocks
  - [ ] Embedded media displays correctly
  - [ ] Mobile preview tested
  - [ ] Loading time acceptable (<3 seconds)

- [ ] **SEO Optimization**
  - [ ] Descriptive page title
  - [ ] Meta description under 160 characters
  - [ ] Header tags used appropriately
  - [ ] Internal links to related content
  - [ ] External links open in new tabs

- [ ] **Sharing Readiness**
  - [ ] Public URL is clean and readable
  - [ ] Social media preview image set
  - [ ] Content appropriate for intended audience
  - [ ] Contact information available if needed

## Accessibility Requirements

### WCAG 2.1 AA Compliance
- **Color Contrast**: 4.5:1 ratio for normal text, 3:1 for large text
- **Keyboard Navigation**: All interactive elements accessible via keyboard
- **Alt Text**: Descriptive alternative text for all images
- **Video Captions**: Closed captions for all video content
- **Text Scaling**: Content remains functional at 200% zoom

### Mobile Optimization
- **Touch Targets**: Minimum 44px size for all interactive elements
- **Text Readability**: Minimum 16px font size
- **Layout**: Responsive design for all screen sizes
- **Loading Speed**: Pages load in <3 seconds on 3G connections

### Inclusive Design
- **Language**: Plain language principles applied
- **Cultural Sensitivity**: Content appropriate for diverse backgrounds
- **Learning Differences**: Multiple ways to consume information
- **Motor Skills**: Accommodations for different physical abilities

## Implementation Guidelines

### Content Creation Workflow
1. **Planning**: Define target age group and learning objectives
2. **Research**: Gather source materials and verify accuracy
3. **Drafting**: Create content following appropriate template
4. **Review**: Apply quality checklist validation
5. **Testing**: Preview on mobile and desktop
6. **Publishing**: Apply publishing standards checklist
7. **Monitoring**: Track engagement and gather feedback

### Style Guide Integration
- **Tone**: Encouraging, positive, instructional
- **Voice**: Active voice preferred, second person ("you")
- **Formatting**: Consistent use of emojis, headings, and callouts
- **Links**: All external links open in new tabs
- **Citations**: Proper attribution for all source materials
