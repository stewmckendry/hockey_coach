# Notion Practice Plan Architecture (Simplified)

## Overview
A streamlined approach to managing practice plans in Notion with a single database for easy tracking and feedback incorporation.

## Page Hierarchy

### Simple Structure
```
🏒 [Team Name] Hockey
├── 📋 Team Dashboard
├── 👥 Team Information (separate)
├── 🗓️ Practice Plans (Database)
│   └── Individual Practice Plan Pages
└── 📚 Other Team Resources
```

## Practice Plans Database Schema

### Core Properties

1. **Title** (Title)
   - Format: "Practice - [Date] - [Focus]"
   - Example: "Practice - Nov 15 - Passing & Defense"

2. **Date** (Date)
   - Practice date and time
   - For chronological sorting

3. **Duration** (Number)
   - Practice length in minutes
   - Default: 60

4. **Focus Areas** (Multi-select)
   - Options: Skating, Passing, Shooting, Systems, Defense, Offense, Goaltending, Special Teams, Conditioning, Fun
   - Can select multiple

5. **Age Group** (Select)
   - Options: U8, U10, U12, U14, U16, U18
   - For filtering similar practices

6. **Players Present** (Number)
   - Attendance count
   - Helps evaluate practice success

7. **Practice Rating** (Select)
   - Options: ⭐⭐⭐⭐⭐ Excellent, ⭐⭐⭐⭐ Good, ⭐⭐⭐ Average, ⭐⭐ Below Average, ⭐ Poor
   - Quick post-practice assessment

8. **Post-Practice Feedback** (Text)
   - **What Worked Well:** Things to repeat
   - **What Didn't Work:** Things to avoid/modify
   - **Player Engagement:** High/Medium/Low
   - **Adjustments for Next Time:** Specific changes

9. **Coach Notes** (Text)
   - Any additional observations
   - Individual player notes
   - Equipment or logistics issues

10. **Next Practice Considerations** (Text)
    - What to focus on based on this practice
    - Skills that need more work
    - Systems to reinforce

### Database Views

#### 1. This Week
- **Filter:** Date is this week
- **Sort:** Date ascending
- **Purpose:** Current practice planning

#### 2. By Rating
- **Sort:** Practice Rating descending, Date descending
- **Purpose:** Find most successful practices to replicate

#### 3. By Focus Area
- **Group by:** Focus Areas
- **Purpose:** Find all practices for specific skills

#### 4. Season Calendar
- **View Type:** Calendar
- **Purpose:** Visual overview of practice schedule

#### 5. Recent Feedback
- **Filter:** Has Post-Practice Feedback
- **Sort:** Date descending
- **Purpose:** Review recent learnings

## Workflow Integration

### Creating Practice Plans
1. Coach requests: "I need a practice plan for Tuesday, 60 minutes, focus on passing"
2. Claude Code:
   - Searches team info for context
   - Researches appropriate drills
   - Generates plan following template
   - Creates Notion page
   - Adds entry to Practice Plans database
   - Returns link to coach

### Post-Practice Feedback
1. Coach opens practice plan page
2. Fills in Post-Practice Review section
3. Updates database feedback fields
4. This feedback is searchable for future planning

### Using Historical Data
When creating new plans, Claude Code can:
- Search for highly-rated practices with similar focus
- Review feedback from recent practices
- Avoid drills/activities marked as ineffective
- Build on successful elements

## Benefits of Simplified Approach

1. **Easy to Maintain**: Single database, simple properties
2. **Quick Feedback**: Post-practice review takes 2-3 minutes
3. **Searchable History**: Find what worked before
4. **No Complex Relations**: Everything in one place
5. **Focus on Content**: Practice plan quality over database complexity

## Future Considerations

If needed later, can add:
- Tags for specific drills (without separate drill pages)
- Season phase tracking
- Weather conditions (for outdoor rinks)
- Special events (tournaments, evaluations)

But starting simple ensures adoption and actual use of the feedback system.
