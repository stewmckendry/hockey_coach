## Contingency Plans

### Group Size Variations
**If fewer players (10-12):**
- Reduce stations to 2
- More individual attention
- Extend skill development time

**If more players (20+):**
- Add third station
- Shorter rotations
- Need extra coach/parent helper

### Time Adjustments
**If running behind:**
- Skip one skill station
- Shorten scrimmage by 3 minutes
- Quick cool-down game

**If ahead of schedule:**
- Add fun relay race
- Extra scrimmage time
- Work on special teams
