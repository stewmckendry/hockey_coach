# Hockey Skills by Age Group

## Overview
Comprehensive list of hockey skills organized by category and age group appropriateness.

---

## Skill Categories and Progression

### 🏃 SKATING SKILLS

**U8 Foundation (6-7 years):**
- Forward skating (straight line)
- Basic stopping (snowplow)
- Getting up from falls
- Gliding on two feet
- Basic balance

**U10 Development (8-9 years):**
- Forward crossovers
- Backward skating (basic)
- Hockey stops (both sides)
- Tight turns
- Edge control (inside/outside)
- Forward to backward transitions

**U12 Refinement (10-11 years):**
- Backward crossovers
- Mohawk turns
- Power skating techniques
- Quick starts and stops
- Agility skating patterns
- Backward to forward transitions

**U14+ Advanced (12+ years):**
- Advanced edge work
- Explosive starts
- Complex transitions
- Speed development
- Skating under pressure
- Advanced agility patterns

## Age Group Summary

### U8 (6-7 years) - FUN FIRST
**Focus:** Basic skills through games
**Ratio:** 80% games, 20% skills
**Key Skills:** Skating, basic puck control, having fun
**Avoid:** Complex tactics, long explanations

### U10 (8-9 years) - SKILL FOUNDATION
**Focus:** Fundamental skill development
**Ratio:** 70% games/fun, 30% skills
**Key Skills:** All basic skills, introduction to team play
**Avoid:** Over-coaching, win-at-all-costs mentality

### U12 (10-11 years) - SKILL REFINEMENT
**Focus:** Refining techniques, basic tactics
**Ratio:** 60% skills, 40% games
**Key Skills:** Advanced individual skills, team concepts
**Avoid:** Specialization, burnout

### U14+ (12+ years) - COMPETITIVE DEVELOPMENT
**Focus:** Advanced skills, systems, competition
**Ratio:** 50% skills, 50% competitive situations
**Key Skills:** All advanced skills, tactical understanding
**Avoid:** Neglecting fun, over-systematizing

## Skill Tracking Tips

1. **Track Weekly:** Note which skills were practiced each week
2. **Rotate Categories:** Ensure all categories get attention
3. **Progressive Building:** Master basics before advancing
4. **Individual Needs:** Some players ready for next level earlier
5. **Seasonal Planning:** Map skills across entire season

## Never/Sometimes/Always Rules

### NEVER
- Skip fundamental skating skills
- Rush progression for younger players
- Ignore safety in skill development
- Focus only on best players

### SOMETIMES
- Challenge advanced players with next level
- Modify drills for skill disparities
- Focus entire practice on one skill area
- Use competition to motivate

### ALWAYS
- Make it fun and engaging
- Provide positive reinforcement
- Ensure all players get touches
- End practice on positive note
